# Omarchy shell plugins, installed with `omarchy plugin add <url> --enable --yes`.
#
# One git URL per line. Blank lines and # comments ignored.
#
# Resolve a plugin's URL from its catalog id rather than guessing from the id:
#   curl -s https://plugins.omarchy.org/catalog.json \
#     | jq -r '.[] | select(.id=="<id>") | .repo'
# The repo name rarely matches the id -- dev.reuk.ports lives at
# RohitKaushal7/omarchy-ports -- so a guess installs somebody else's plugin.
